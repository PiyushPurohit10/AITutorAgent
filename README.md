# PS04: Personalized AI Learning Agent

An interactive AI learning agent designed for structured concept explanations, guided Q&A, and knowledge checks tailored to individual learner progress.

## Customization & Learning Flow
1. **Topic & Level Selection:** The learner chooses a subject/topic and difficulty or pacing preference so explanations match their current understanding.
2. **Guided Concept Breakdown:** Breaks down core ideas step by step with concrete examples rather than dumping walls of text.
3. **Active Recall & Checkpoints:** Prompts the learner with follow-up questions and quick checks to verify grasp before moving forward.
4. **Adaptive Iteration:** Adjusts explanations and hints based on where the learner gets stuck.
